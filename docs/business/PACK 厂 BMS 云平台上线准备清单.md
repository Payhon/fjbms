# PACK 厂 BMS 云平台上线准备清单

2026 年 11 月 11 日

本清单适用于 PACK 厂发布自有品牌的 iOS 和 Android App、微信小程序，并独立部署云平台和 Web 后台。请项目负责人逐项确认，账号、备案资料和样机可并行准备。

## 一  项目启动时

| 完成 | 准备事项 | 需提供或确认 |
| --- | --- | --- |
| □ | 主体与负责人 | 提供企业全称、统一社会信用代码及营业执照信息，指定项目对接人、平台账号管理员和备案负责人。由实际运营主体持有开发者账号、云账号、域名与发布签名资产。 |
| □ | 首发范围 | 确认上线地区、语言、首发渠道及计划日期。与富嘉电源核对首发设备型号，确认后台保留的角色、经销商及门店层级，以及电池出厂、绑定、流转和售后流程。 |
| □ | 品牌和素材 | 确认 App 和小程序的名称、简称及所需语言版本。提供 Logo 源文件及高清 PNG、品牌主色，以及计划使用的启动图和首页 Banner。备案与渠道资料统一使用确认后的名称。 |
| □ | Apple 组织账号 | 以企业主体加入 Apple Developer Program。准备 D-U-N-S（邓白氏）编号、启用双重认证的 Apple 账户、企业域名邮箱及公开官网，由有签约权限的经办人申请。开通后在 App Store Connect 邀请开发人员。 [Apple 注册说明](https://developer.apple.com/cn/help/account/membership/program-enrollment) |
| □ | 微信小程序账号 | 以企业主体在微信公众平台注册并办理所需认证，确认名称、服务类目和对应资质。提供小程序 AppID，添加开发者和体验成员。 [微信公众平台](https://mp.weixin.qq.com/) |
| □ | Android 发布 | 确定首发渠道。通过应用商店发布时，开通企业开发者账号，并核对渠道要求的应用备案号、软件著作权证书或适用的权属证明。 [小米资质说明](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2251) |
| □ | 云账号与域名 | 准备已完成企业实名认证的阿里云账号和可管理解析的企业实名域名。已有资源的，请提供所在地域、到期时间及备案状态。 |
| □ | 中国内地备案 | 按接入与发布范围核对网站 ICP 备案、App 备案和小程序备案。App 按接入商流程办理，小程序在微信公众平台办理。准备主体材料和负责人核验资料，由开发团队配合提供应用特征信息。上线后按适用要求办理公安联网备案。 [工信部通知](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2023/art_dd783a581c9644a4aee10afa582811db.html) · [阿里云备案指引](https://help.aliyun.com/zh/icp-filing/basic-icp-service/getting-started/quick-sta-rt-for-icp-filing-for-personal-app) |

首批请回传企业主体、联系人、首发地区与渠道、应用名称、域名、账号和备案办理进度，以及样机预计到位时间。

## 二  部署和设备联调前

| 完成 | 准备事项 | 需提供或确认 |
| --- | --- | --- |
| □ | 云服务器与容量 | 提供预计设备总量、同时在线量、4G 上报频率和数据保留周期。与开发团队确认阿里云 ECS 地域、备案条件、规格和备份方案后再采购。开发团队按部署方案配置 PostgreSQL、Redis 和 MQTT 服务。 |
| □ | 子域名与证书 | 为管理后台、API、设备接入和文件访问规划子域名，安排 DNS 配合及相应 TLS 证书。按接口实际使用情况配置微信小程序的 HTTPS 请求、上传、下载及 WSS 通信域名。 [小程序域名配置](https://help.aliyun.com/zh/dws/user-guide/using-domain-names-in-wechat-applets) |
| □ | 企业邮箱 | 如启用邮箱验证码、邮箱找回密码或邮件通知，准备企业发件地址及可用的 SMTP 服务，确认发件显示名、服务器地址、端口和加密方式。可使用企业邮箱服务商提供的 SMTP 服务。 |
| □ | 对象存储 | 确认阿里云 OSS 的地域、存储空间（Bucket）及访问授权。按启用功能准备图片、附件、App 安装包和 OTA 固件的存储与下载配置。 |
| □ | 短信和推送服务 | 启用手机号验证码或短信通知时，准备短信服务账号、签名和模板。启用 App 推送时，准备新应用的 UniPush 及关联 uniCloud 空间权限，按渠道配置 iOS APNs 和 Android 厂商通道。 [UniPush 开通说明](https://uniapp.dcloud.net.cn/tutorial/app-push-unipush.html) |
| □ | 样机与设备资料 | 按首发型号提供可上电的 BLE、4G 样机及必要配件，附 BMS 型号、固件版本、SN、二维码样例和配对说明。4G 样机附 IMEI、可用物联网卡和资费状态。启用 OTA 时提供匹配固件包与适用硬件版本，保留仪表功能时提供仪表样机。 |
| □ | 4G 设备接入 | 请富嘉电源与设备技术负责人确认模组如何配置 MQTT 服务地址、认证信息并写入量产设备。已有设备需切换时，提供脱敏清单，确认设备归属、是否需刷写固件、切换批次及回退安排。涉及账号或历史数据迁移时，另确认范围和数据样例。 |

项目协作使用平台成员邀请或限定权限授权。AppSecret、SMTP 授权码、云访问密钥和签名私钥通过约定的安全渠道交接，备案证件按官方平台要求提交。

## 三  提审和验收前

| 完成 | 准备事项 | 需提供或确认 |
| --- | --- | --- |
| □ | 应用标识与签名 | 确认 iOS Bundle ID、Android 包名、DCloud AppID 和微信小程序 AppID。开发团队配合配置各端发布签名及备案所需的公钥、签名指纹等信息。请平台管理员确认签名资产保管人和续期责任。 |
| □ | 上架与客服资料 | 提供应用简介、支持的电池型号、主要使用场景、企业介绍和客服联系方式。准备应用图标、商店截图、公开的客服或支持页面，以及审核联系人的姓名、电话和邮箱。 |
| □ | 隐私和协议 | 由运营主体确认隐私政策和用户协议，提供公开访问地址。梳理账号信息、设备标识、遥测数据和第三方 SDK 的使用情况，明确蓝牙、相机、定位等权限用途及账号注销方式。按渠道填写 App 隐私声明和小程序用户隐私保护指引。 [Apple 隐私说明](https://developer.apple.com/cn/help/app-store-connect/manage-app-information/manage-app-privacy) |
| □ | 审核演示与发布 | 准备可登录的测试账号、测试二维码、配对步骤和硬件演示视频，按审核要求配合提供样机。iOS 由实际运营的 PACK 厂主体提交，审核资料说明本品牌支持的设备、服务与实际使用场景。Apple 对模板和重复 App 有专门的审核条款。 [Apple App 审核指南](https://developer.apple.com/cn/app-store/review/guidelines/) |
| □ | 联调和验收人员 | 确认 iOS、Android、微信小程序及 Web 后台的验收人员和测试时间。按约定范围验证登录、扫码绑机、BLE 连接、4G 上报、后台权限和 OTA。同步确认上线后的告警、续费和版本发布联系人。 |

回传准备进度时，请为待完成事项注明负责人和预计完成日期。
