# FEAT-0030 UniApp 页面多语言文案补全 - 发布说明

- status: in_progress
- owner: payhon
- last_updated: 2026-09-24
- related_feature: FEAT-0030
- version: v0.1.0

## 1. 变更摘要
- 补齐 UniApp 首页、设备详情及常用页面的多语言文案调用。
- 新增中英文词条，减少页面语言切换后的硬编码残留。
- 同步清理通用提示模块中的硬编码 toast / modal 文案。
- 升级弹窗与升级确认链路已纳入多语言方案，避免自动升级提示仍出现中文硬编码。
- 修复微信小程序英文环境中设置页退出登录、账号注销及其他原生确认弹窗因按钮文案超长而无法弹出的问题；账号页弹窗调用失败时会提示用户。

## 2. 发布关注点
- 需重点回归首页、设备详情、“我的”页及设备添加相关流程。
- 需补充回归升级弹窗、后台下载提示与安装确认弹窗的中英文显示。
- 需在中文、英文两种语言下检查关键页面是否存在 key 原样透出。
- 需重新构建微信小程序包，在真机中回归退出登录与账号注销的确认、取消路径；源码校验不代表已完成真机验收。

## 3. 回滚说明
- 如发现页面文案异常，可回滚本轮原生弹窗短词条及调用处变更，恢复原文案；回滚后微信小程序英文弹窗超长问题会重新出现。
