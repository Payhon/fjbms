# FEAT-0079 蓝牙扫描名称恢复

- status: review
- owner: payhon
- last_updated: 2026-10-29
- related_feature: FEAT-0079
- version: v0.1.0

## 背景与目标
蓝牙模块上电修改名称期间可能广播异常名称；iOS 扫描结果中设备名称不一定随广播名称更新，导致列表持续显示乱码。优化扫描结果名称选择，不要求连接设备刷新名称。

## 验收标准
- 优先显示有效广播 localName，回退有效 name；过滤明显控制字符和替换字符，不将其展示为名称。
- 有效广播名称不被后续缺失或异常广播覆盖；支持的广播 MAC 即使没有名称也可显示未知设备并匹配，未识别设备仍受原身份过滤约束。
- 保持扫码匹配、列表去重、扫描生命周期及 iOS 续扫行为；不自动连接设备。
- 区分自动化与真机结果，iOS 小程序/App 上电时序及其他平台回归需真机确认。

## 风险及回滚
上层未收到正确广播名称时，客户端无法凭空恢复；实际广播和系统回调仍需真机证据。可回滚移动端名称选择及过滤改动，无协议、数据库或服务变更。
