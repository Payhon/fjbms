# FEAT-0077 蓝牙重连搜索提速与阶段提示

- status: review
- owner: payhon
- last_updated: 2026-10-16
- related_feature: FEAT-0077
- version: v0.1.0

## 1. 背景与目标

用户授权按连接路径分析优化，并要求保留现有功能。已添加设备进入详情时，重新搜索的固定窗口和统一“连接中”提示造成等待及困惑。

## 2. 范围

- 重连扫描复用现有 MAC/广播匹配，发现目标立即结束等待，停止扫描后连接；无匹配时保留 iOS 1500+3500ms、其他平台 5000ms 上限。
- 详情连接提示按实际阶段展示“搜索设备中 / 连接设备中 / 初始化中”，中英文一致覆盖顶部和遮罩。
- 连接任务共享时，新加入的详情页能收到当前及后续阶段；旧页面/旧会话不能覆盖当前提示。
- 保留直接连接候选、健康探测、缓存/租约、取消、服务发现重试、校时、轮询、配网交接、4G/MQTT 与 OTA 规则。后台请求顺序与时限不变。
- 不新增依赖、后端接口、数据库变更，不打包发布或操作真实设备。

## 3. 用户价值

减少扫描已发现目标后的空等，让等待阶段可见，不通过缩短设备兼容性等待来提速。

## 4. 验收标准

1. 覆盖扫描启动时/扫描期间命中、无关设备、不匹配超时、第二阶段命中、取消与异常清理。
2. 多个连接调用仍共享一次物理连接，阶段回调异常不影响连接，完成后不遗留监听。
3. 直接连接显示连接阶段；物理连接成功后服务发现及校时显示初始化；真实扫描期间显示搜索。
4. 旧会话/卸载/重连后的回调不影响新状态；4G 继续使用原连接提示。
5. 类型、微信/APP 分支 SFC 与现有 BLE/校时/仪表/OTA/主动均衡回归通过；真机验收前保持 review。

## 5. 风险与约束

提前结束扫描依赖现有匹配规则，不能降低匹配精度或误连其他 MAC。共享任务与页面切换需隔离阶段通知；静态和模拟测试不代表真实 BLE 耗时。

## 6. 回滚方案

撤回本功能的扫描提前结束和阶段提示接入，恢复固定窗口与统一连接文案；不涉及数据迁移，不撤回其他未提交功能。
