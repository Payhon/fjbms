# FEAT-0074 蓝牙 BMS 连接后自动校时

- status: review
- owner: payhon
- last_updated: 2026-09-16
- related_feature: FEAT-0074
- version: v0.1.0

## 背景与目标

用户已确认本规格。蓝牙连接成功且通知订阅就绪后，自动向纯蓝牙 BMS 写入当前时间，避免设备时间未校准。

## 范围与规则

- 同时满足实际蓝牙直连、连接 MAC 首字节 AC、真实 `bms_comm_type=1` 才发送。
- AA 仪表、其他 MAC、4G（2）、双模（3）、未知类型均跳过；不能用页面默认值推断纯蓝牙。
- 使用标准 Unix 秒 `Math.floor(Date.now()/1000)`，不做时区偏移。
- 每次新连接尝试一次，缓存复用/并发调用/配网交接不重复；未知类型后续确认后允许补校时。
- 校时拒绝、超时、断连仅记录日志，不弹窗、不重发、不阻止正常读取；重连可再次尝试。
- 覆盖首页、详情、配网和 OTA 后重连；不新增 UI、依赖、后端接口、数据库结构。

## 协议与验收

- 复用 `syncTime`，功能码 0x10，目标 0x01，寄存器 0x057C～0x057D，4 字节无符号大端时间戳。
- 秒数 1760674088 必须生成 `7F 55 FE 01 10 05 7C 00 02 04 68 F1 C1 28 D7 93 FD`。
- 输入必须为 0～0xFFFFFFFF 的整数；拒绝非法输入，不能通过位运算静默截断。
- 响应及原生写入 API 超时均为 3000 ms；关闭 iOS 超时切换写入方式重发，保留其他请求默认行为。
- 自动化覆盖资格、去重、重连、协议、异常恢复、请求参数透传；Android/iOS/微信小程序抓包与设备时间验证通过才完成。

## 风险与回滚

- 设备资料错误可能影响资格判断，以真实通信类型为准；旧固件可能拒绝或不响应，失败后继续业务。
- 自动化模拟不代表真机验收；硬件验收前保持 review。
- 回滚自动校时接入及其辅助逻辑即可，无数据库迁移。
