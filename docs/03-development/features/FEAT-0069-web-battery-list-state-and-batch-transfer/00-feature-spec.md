# FEAT-0069 Web 电池列表状态记忆与批量调拨 - 功能规格

- status: approved
- owner: payhon
- last_updated: 2026-07-24
- related_feature: FEAT-0069
- version: v0.1.0

## 1. 背景与目标
- `BMS 管理 > 电池列表` 在切换到其他功能页后会重新创建，已执行的筛选和分页恢复为默认值。
- 电池列表已有跨分页勾选与多种批量操作，但调拨仍只能逐台执行。
- 本次目标：
  1. 在当前浏览器登录会话内记忆已执行的筛选、分页和高级筛选展开状态。
  2. 新增复用跨分页勾选结果的批量调拨能力。
  3. 批量调拨继续执行 FEAT-0045 的角色、组织类型和组织树限制。

## 2. 范围（In Scope / Out of Scope）
### In Scope
- 电池列表查询状态使用 `sessionStorage` 持久化并在页面初始化前恢复。
- 查询、分页和重置与跨页选择状态联动。
- 新增后台批量调拨接口、按钮权限、管理端弹窗和中英文文案。
- 批量调拨采用逐台独立事务和部分成功返回。
- 文档、权限迁移和项目看板同步。

### Out of Scope
- 不启用整页 `keepAlive`。
- 不持久化勾选项、弹窗、加载状态或未执行查询的临时输入。
- 不新增调拨审批、签收或整批事务。
- 不修改 UniApp。

## 3. 用户价值
- 用户切换功能页或刷新后可继续使用上次已执行的电池筛选和分页。
- 用户可跨多个分页选择电池并一次完成调拨。
- 部分失败时保留失败电池供重试，避免重复选择和重复调拨成功项。

## 4. 验收标准
1. 执行查询后切换功能页或刷新浏览器，筛选条件、已执行 API 参数、高级筛选展开状态、页码和每页条数正确恢复。
2. 未点击查询的临时输入不写入记忆；重置、退出登录或账号切换后不恢复旧状态。
3. 查询或重置清空勾选，单纯翻页和切换每页条数保留跨页选择。
4. 批量操作菜单新增“批量调拨（N）”，并受独立按钮权限控制。
5. 批量调拨目标类型与单台调拨一致：厂家为 PACK/经销商，PACK 为经销商/门店，经销商仅门店，门店不可执行。
6. 批量接口对重复设备 ID 去重，逐台返回成功/失败汇总和失败明细。
7. 部分成功时仅保留失败电池勾选；全部成功时清空选择；请求级失败时保留全部选择。

## 5. 风险与约束
- `sessionStorage` 仅在当前浏览器会话内有效，关闭会话后自动失效。
- 调拨入口显隐仅改善体验，最终以后端租户、组织归属和组织树校验为准。
- 批量操作允许部分成功，前端必须明确展示失败数量和逐台原因。
- 跨分页缓存只包含用户曾加载并勾选的行摘要，不额外查询详情。

## 6. 回滚方案
- 回滚前端会话状态和批量调拨入口，恢复现有单台调拨。
- 回滚批量调拨 API、服务和 `backend/sql/64.sql` 权限增量。
- 已成功写入的调拨记录不做数据回退，可通过既有回退能力处理。
