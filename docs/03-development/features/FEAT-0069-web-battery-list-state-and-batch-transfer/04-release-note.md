# FEAT-0069 Web 电池列表状态记忆与批量调拨 - 发布说明

- status: review
- owner: payhon
- last_updated: 2026-07-24
- related_feature: FEAT-0069
- version: v0.1.0

## 1. 发布内容
- 电池列表会话级查询状态记忆。
- 跨分页批量调拨和部分成功反馈。
- 新增批量调拨按钮权限和后端接口。

## 2. 影响范围
- Web 管理端、后台电池生命周期服务、页面元素权限。
- 不影响 UniApp，不修改数据库表结构。

## 3. 升级步骤
- 执行 `backend/sql/64.sql`。
- 发布后端与前端。
- 使用厂家、PACK、经销商和门店账号回归权限与调拨矩阵。

## 4. 回滚步骤
- 回滚对应前后端版本。
- 如需移除入口，撤销 `bms_battery_list_batch_transfer` 权限分配。
- 不回退已成功产生的调拨记录。

## 5. 已知问题
- 后端全量测试依赖本地告警缓存和 PostgreSQL 测试配置；缺少环境时既有用例会空指针，详见测试报告。
- 浏览器多角色与目标数据库权限迁移仍待发布环境验收。
