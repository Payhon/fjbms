# FEAT-0078 iOS 扫码超时后继续搜索

- status: review
- owner: payhon
- last_updated: 2026-10-28
- related_feature: FEAT-0078
- version: v0.1.0

## 背景与目标
设备密集时二维码 MAC 匹配可能在 30 秒内未发现目标。iOS 微信小程序及 App 支持超时后保留结果继续搜索。

## 范围与验收
- iOS 二维码 MAC 匹配超时后，提示旁显示带图标的“接着扫描”；中英文支持。
- 继续搜索保留结果，按 deviceId 更新或追加设备，并继续匹配目标；支持多轮与失败重试。
- 原“开始扫描”仍清空列表，其他平台、手动搜索及非超时错误不出现初始入口。
- 保留原有过滤、30 秒时长、匹配跳转、扫描协调及页面生命周期行为。

## 风险与回滚
持续搜索不能保证系统发现目标，需真机验证。回滚本功能移动端修改及相应文案，不涉及接口、协议、数据库或服务。
