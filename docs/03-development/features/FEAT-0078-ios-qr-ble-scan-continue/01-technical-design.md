## 方案
扫描启动增加保留列表选项；超时用独立状态标识继续入口，继续启动失败保留该入口与列表。每轮独立记录本轮是否解析到有效广播 MAC，供无服务过滤降级使用。沿用现有按 deviceId 更新和目标匹配、串行扫描、租约与清理逻辑。

## 接口与兼容性
仅页面内部状态及中英文文案变化，不新增外部 API 或数据迁移。iOS 使用系统平台标识，微信及 App 共用逻辑。

## 验证
运行扫描行为回归、页面类型与编译检查；iOS 微信小程序和 App 密集设备真机验收独立记录。
