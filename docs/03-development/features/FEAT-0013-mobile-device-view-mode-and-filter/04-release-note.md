# FEAT-0013 移动端设备添加分流、首页视图切换与筛选增强 - 发布说明

- status: in_progress
- owner: payhon
- last_updated: 2026-09-28
- related_feature: FEAT-0013
- version: v0.1.3

## 1. 发布内容
- 移动端设备添加按用户类型分流：
  - 终端用户添加时绑定并激活；
  - 机构用户添加时仅加入“我的设备”。
- “我的”页面新增机构用户首页视图切换图标。
- 首页“我的设备”支持按模式查看：
  - 我添加的设备
  - 终端用户绑定设备
- 首页筛选图标支持真实筛选交互，覆盖终端用户与机构用户场景。
- 修复 OpenHarmony 微信长按设备卡片时把原生事件对象当成设备对象、导致解绑提交 `device_id="undefined"` 的问题；同时增加无效设备 ID 请求前拦截。
- 修复终端用户改名污染设备全局名称：个人自定义名称保存在当前绑定记录，解绑重绑后恢复设备原始名称；现有移动端请求无需改版即可走新逻辑。
- v0.1.3 修复解绑/移除成功后微信扫码快照未删除设备，导致再次扫码跳过重新添加、进入旧详情而无法连接的问题；保留其他已添加设备的扫码直达及现有一次性自动连接规则。
