## 变更

移动端连接后通过新增 `0x0136` 电流查询识别主动均衡板，在仪表盘显示均衡电流，复用原状态返回中的逐电芯均衡位设置淡黄色背景。不发送独立均衡状态查询。

2026-10-17 修正：充电、放电开关下方的均衡状态行始终显示并占据完整下一行，开关直接反映返回的均衡位；电流查询失败、不支持或旧快照缺字段时只隐藏电流值，不移除均衡行。

## 交付范围

代码、测试、文档和看板已更新，移动端代码已分项提交并推送，等待真实设备验收。客户端尚未发布，未部署后端/Web；无数据库迁移、依赖、权限或新增业务配置。版本号变更独立提交。

## 风险

- 不支持电流寄存器且不回复的旧板，每轮可能多等待一个请求超时；不阻断普通状态读取。
- 旧版完整快照没有电流字段时不显示电流，均衡行仍按已有状态位显示；未返回状态时开关保持关闭并禁用。
- 真实硬件、电流校准、三端原生布局及 BLE/MQTT 时序尚未验收。

## 回滚

回退本功能协议客户端、状态类型/解析、详情状态指纹和两个组件修改。新增字段可选，无持久化迁移，旧客户端不依赖该字段。
