# FEAT-0076 技术设计

- status: review
- owner: payhon
- last_updated: 2026-10-17

## 1. 读取与建模

`BmsClient.readAllStatus()` 首先尝试 `readRegisters(0x136, 1)`，沿用当前传输的超时参数与取消检查，异常记录调试信息并继续。将实际读取结果单独传入 `parseStatusRegisters`，不从旧板兼容拼接数组中的补零推断能力。

`BmsStatus.cell.balanceCurrentA` 为可选 `number | null`：非负数字代表已确认主动均衡电流；null/缺失代表不支持或未知，不显示电流值。不改变原始 `cell.balancing` 位数组及其协议含义。高字节除以 10 得到安培，低字节忽略。

## 2. 展示

根据 2026-10-17 测试反馈，仪表盘在充电、放电开关下方始终保留均衡行，以 `grid-column: 1 / -1` 占满下一行。只读开关直接使用 `cell.balancing.some(Boolean)`，不依赖电流字段；仅电流文本受有效电流条件控制，固定一位小数。没有状态时开关按原有充放电开关约定保持关闭并禁用。

电芯页仍需有效正电流且当前电芯均衡位开启，才设置淡黄色背景。沿用现有中英文标题，不新增依赖、权限或配置。

## 3. 数据路径与兼容

实时蓝牙与 MQTT 共用客户端；完整云快照保留可选字段，旧快照和仅平铺遥测不猜测板型。Bluetooth 上报状态指纹须包含均衡电流和位变化，以便状态变化及时进入原有完整快照上报。保留现有状态查询、旧板告警补齐和动态区读取，不增发均衡状态查询。

## 4. 验证

用真实 BmsClient 配合模拟传输验证请求帧、顺序、状态位解析、0/FF/正电流、超时、取消、刷新和旧板补零；渲染实际 Vue 模板验证显隐、电流和电芯样式；运行类型及受影响既有回归。真机和发布独立验收。
