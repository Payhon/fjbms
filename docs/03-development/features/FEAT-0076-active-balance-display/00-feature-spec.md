# FEAT-0076 主动均衡电流与电芯状态显示

- status: review
- owner: payhon
- last_updated: 2026-10-17
- related_feature: FEAT-0076
- version: v0.1.0

## 1. 背景与目标

依据 `doc/oriigin/均衡电流文档.docx`、`doc/oriigin/主要工作寄存器261016.xlsx` 和用户本轮确认，小程序连接后查询主动均衡电流，均衡状态复用现有状态查询返回，不增加独立均衡状态查询。用户已授权按此方案实施。

## 2. 范围

- UniApp 共用协议客户端及仪表盘、电芯页，兼容微信小程序、Android、iOS 的蓝牙与 MQTT 实时链路。
- 每轮状态读取先单独读取 `0x0136` 一个寄存器，读取高字节，低字节忽略；高字节 `FF` 不支持，其他值为主动均衡电流，分辨率 `0.1A/bit`。
- `00 FF` 是有效主动均衡回复，显示 `0.0A`。工作表通用备注的“0 无效”与详细案例冲突，以新需求流程图和案例为准。
- 现有 `0x0100` 状态返回中的 `0x011B/0x011C` 继续表示 1～16、17～32 串均衡位。
- 本轮不改 Web、后端、权限、均衡控制命令，不发布、不操作真实设备。

## 3. 用户价值

用户能查看设备返回的均衡状态、有效的主动均衡电流，并区分哪些电芯正在主动均衡。

## 4. 验收标准

1. `0F FF` 显示 `1.5A`，`00 FF` 显示 `0.0A`，`FF FF`、查询失败或旧快照缺字段时只隐藏电流值和电芯均衡效果，不隐藏仪表盘均衡状态行。
2. 根据用户 2026-10-17 的测试反馈，充电、放电开关下方始终显示一整行均衡状态与只读开关，开关按现有状态查询返回的均衡位显示，不依赖电流查询结果。此条替代此前整行按主动均衡能力隐藏的处理。
3. 只有主动均衡电流大于零且对应状态位为 1 时，该电芯显示淡黄色背景；不覆盖最高/最低电压文字颜色。
4. 电流归零、均衡位关闭或不支持时清除高亮；设备重连/切换不复用其他设备板型。
5. 新增请求仅为 `0x0136` 单寄存器电流查询，不单独查询均衡位，不改变原固定状态读取范围。
6. 电流查询错误不阻断普通状态读取，取消后不继续排队；旧板未读寄存器补零不能被误判为主动均衡。

## 5. 风险与约束

电流随现有状态轮询刷新，不增加独立定时器。旧板不支持时可能增加一个请求的等待；失败不缓存为板型结论。已有云端快照缺电流字段时仅隐藏电流，均衡行保留；新的完整交互快照可自然携带该字段。真实设备时序及三端视觉仍需验收。

## 6. 回滚方案

回退本功能移动端协议读取和两个展示组件；新增状态字段保持可选，无数据库迁移、配置和持久化格式强制升级。
