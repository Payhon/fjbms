- last_updated: 2026-11-12

## 通知渲染

后台基础布局沿用现有 `device_online` 事件。上线和下线共用 Naive UI 通知渲染，根据 `is_online` 选择通知类型、状态文案和提示音。标题只显示状态，设备名称作为说明独立渲染，CSS 负责单行省略，原文用于鼠标悬停提示。详情按钮在空间不足时换行，点击后通过现有路由传递 `d_id`。

## 交互

Naive UI 的可滚动通知容器在过渡期间会扩展到视口高度。通过提供器的 `containerClass` 为容器设置点击穿透，并为实际通知卡片恢复点击命中。沿用组件自带的键盘可达关闭按钮、滚动和 5 秒退出计时。应用不主动转移页面焦点。

事件字段、路由参数与通知提供器接口沿用原有契约。
