# FEAT-0080 后台设备上下线通知优化

- status: review
- owner: payhon
- last_updated: 2026-11-12
- related_feature: FEAT-0080
- version: v0.1.0

## 背景与目标

后台将设备名称和状态拼接在通知标题内。较长的连续编码会溢出标题区域，遮住右上角的关闭按钮。通知容器的空白区域也可能拦截页面点击。

## 验收标准

- 状态标题与设备名称分开显示。长编码单行省略，鼠标悬停可查看全称。在桌面、320px 窄屏和浏览器放大时，状态和关闭按钮可见，详情入口可操作。
- 收到通知时保留当前输入焦点。多条通知可分别关闭，卡片间隙和进出场动画产生的容器空白允许点击下方页面。关闭和详情入口支持鼠标及键盘。
- 保留中英文文案、5 秒自动关闭、上下线提示音和按事件 `device_id` 跳转详情。回归登录成功通知。

## 风险与回滚

点击穿透样式依赖当前版本通知容器和卡片的结构。通过模拟事件验证布局与交互，回滚时恢复本次 Web 前端修改。
