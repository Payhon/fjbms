## 浏览器回归

用本地 SSE 服务向实际后台布局和 Naive UI 通知提供器推送模拟事件。通过 Playwright 在 Chrome 和 Chromium 中验证。

- 桌面 1280px 中文和 320px 窄屏英文通知通过。短编码完整显示，超长无空格编码单行省略，原文可悬停查看。状态、关闭按钮与详情按钮均在卡片内。
- Chromium 浏览器 200% 缩放通过。长编码未遮挡关闭按钮，鼠标可关闭通知。
- 连续通知弹出时输入框保持焦点，文字可继续录入。点击卡片间隙和进出场动画的空白区域均命中页面。两条通知可分别用键盘、鼠标关闭。
- 设备详情支持键盘和鼠标跳转，路由收到事件对应的 `d_id`。未手动关闭的设备通知到时自动消失。播放调用选择了对应的上线、下线音频，实际音频输出未验证。
- 模拟登录成功通知通过共用提供器显示并可关闭。生产账号登录后的真实设备事件待验收。
