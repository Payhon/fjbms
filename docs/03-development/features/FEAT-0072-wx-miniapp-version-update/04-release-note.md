# FEAT-0072 微信小程序版本更新检测 - 发布说明

- status: review
- owner: payhon
- last_updated: 2026-08-13
- related_feature: FEAT-0072
- version: v0.1.0

## 1. 发布内容

- 微信小程序启动时自动检测微信平台的新版本。
- 新版本下载完成后提示用户，确认后自动应用更新并重启。
- 后台下载完成的更新会在用户再次进入前台时提示。

## 2. 影响范围

- 仅 `fjbms-uniapp` 微信小程序编译目标。
- Android/iOS App 现有更新中心不受影响。

## 3. 升级步骤

- 在微信公众平台上传、审核并发布新版本。
- 旧版本用户下一次进入小程序时由微信更新管理器检测并下载。

## 4. 回滚步骤

- 回滚微信小程序更新控制器及 `App.vue` 生命周期接入。

## 5. 已知问题

- 更新检测和下载受微信版本灰度、网络状态与客户端缓存调度影响。
- 本地检查不能替代微信开发者工具模拟更新或新旧发布版本的真机验收。
