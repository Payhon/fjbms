# FEAT-0073 设备详情 UUID 复制与 4G IMEI 展示 - 功能规格

- status: review
- owner: payhon
- last_updated: 2026-08-30
- related_feature: FEAT-0073
- version: v0.1.0

## 1. 背景与目标

- 移动端设备详情页导航标题可能显示包含 UUID 的默认设备名称，UUID 过长时会被截断，不便于售后核对设备。
- 仪表盘底部当前固定显示 MAC，4G 或双模设备通过 4G 链路查看时无法直接核对 4G 模块 IMEI。
- 目标是在不改变设备名称、连接和数据读取链路的前提下，提供完整 UUID 查看/复制能力，并按当前连接链路显示正确设备标识。

## 2. 范围

### In Scope

- 仪表盘页在连接状态与仪表盘内容之间显示完整 `item_uuid`。
- UUID 卡片支持点击复制，并提供中英文成功/失败反馈。
- APP 电池详情接口新增 `imei` 字段。
- 4G/双模设备非蓝牙链路显示 IMEI，双模设备蓝牙链路继续显示 MAC。
- 补充标识选择自动化测试、接口测试、Swagger 和项目看板。

### Out of Scope

- 不修改导航栏现有设备名称及其单行截断行为。
- 不修改首页标识、绑定、扫码、连接、轮询、数据仲裁、OTA 或历史记录逻辑。
- 不新增数据库字段或迁移。

## 3. 用户价值

- 售后可直接看到并复制完整 UUID，减少手工抄录和截断造成的设备识别错误。
- 4G 设备详情展示真实 IMEI，与现场 4G 模块核对口径一致。

## 4. 验收标准

1. 默认仪表盘页在连接状态下方展示完整 `item_uuid`，窄屏允许换行且无横向滚动。
2. 点击有效 UUID 卡片复制的内容与接口返回值去除首尾空格后完全一致，并显示成功或失败反馈。
3. UUID 为空时显示 `UUID: -`，不触发剪贴板写入。
4. `bms_comm_type=2/3` 且当前不是蓝牙连接时，仪表盘原 MAC 位置显示 `IMEI: <值>`。
5. 上述 4G 场景 IMEI 为空时显示 `IMEI: -`，不得回退 MAC、ICCID 或 `comm_chip_id`。
6. 双模设备当前使用蓝牙连接、以及纯蓝牙设备，继续显示格式化 MAC。
7. 电芯、参数、历史页面不显示 UUID 卡片，现有业务行为不变。

## 5. 风险与约束

- App/H5 仪表文本由 Vue 覆盖层渲染，微信小程序由 Canvas 绘制，两条路径需同步更新和验证。
- UUID 卡片需保留至少 44px 等效触控高度，并保证完整字符串不会撑出页面宽度。
- 真机或微信开发者工具验证完成前，不将功能状态标记为 `done`。

## 6. 回滚方案

- 回滚 APP 电池详情接口 `imei` 字段扩展。
- 回滚 UUID 卡片、复制交互和仪表盘通用标识选择逻辑，恢复固定显示 MAC。
- 本功能不涉及数据迁移，回滚无需处理数据库。
